# Robotic Arm Project
An independent engineering project where I am designing and building a robotic arm from the ground up.
## Goals
-Design the robotic arm using Onshape
-Learn mechanical design and kinematics 
-Program the arm using Python and a microcontroller
-Build and test psychical components
-Document the engineering process 
-Improve the design through testing and iteration
## Technologies 
-Onshape
-Python
-CAD
-Electronics
-3D printing
-Robotics
